# Historical: Battle of Tukayyid — Version 0.2 Playtest

Version 0.2 expands the campaign for use with Alpha Strike and clarifies the required publications.

Changes in this version:

- Added Alpha Strike campaign PV limits, Starting SP, and Support Allocations.
- Added Alpha Strike repair, replacement, rearming, alternate-munition, and healing costs.
- Added Alpha Strike destruction, recovery, pilot and crew survival, injury, and Edge rules.
- Clarified the supported Classic BattleTech and Alpha Strike rules paths.
- Removed the separate SMF-formatted campaign-rules file.
